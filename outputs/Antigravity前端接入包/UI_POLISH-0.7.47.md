# LumiBar 0.7.47 界面协作更新

2026-11-15，协议保持 v1。此前新增的插件菜单见 PLUGIN_MENUS-0.7.46.md 与 PluginMenusExample.cs，仅有托盘和设置左侧两个位置，胶囊右键没有菜单。

## 天气城市栏

- 标题右侧刷新图形缩小到 15 DIP，点击区域仍是 38 × 38 DIP。
- 删除城市栏右端单独的定位按钮。首个入口统一表示系统定位：尚未取得位置时只显示小圆定位图标；已取得位置时显示图标和城市名。
- 点击定位入口执行 cities.locate，切换到 Windows 当前返回的位置并打开自动定位。不要执行 cities.select，不要自动把定位城市加入收藏。
- 收藏城市紧跟定位入口；加号直接接在最后一个收藏城市之后，整行共用水平滚动。手动选择收藏城市会退出自动定位，定位入口仍保留本次会话取得的位置名称。
- state.weather.locatedCity 新增可选、只读 City|null 字段，是当前进程记住的定位结果，不持久化到默认设置。旧后端缺少此字段时显示无名称定位图标。locationBusy/status 沿用现有字段。诊断导出会删除 locatedCity。

## 音乐胶囊

- 展开状态的歌曲封面视觉上向右平移 2 DIP；胶囊外部宽度和文字列位置保持。Lite 封面沿用原来位置。
- 用户试看实心播放图标后决定恢复细线图标。上一首、播放、暂停、下一首统一沿用原有 Segoe Fluent 图标；不要跟进实心版本。
- 封面双色着色、频谱、悬停控制与跑马灯逻辑沿用，不改变音量。

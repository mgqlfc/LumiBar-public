# 当前视觉规范

基准：Windows 内置前端 0.7.56。尺寸使用 DIP；移植到 macOS 时先按同数值 point 排布，再处理菜单栏高度、刘海和屏幕可用空间。截图对应的实测尺寸见 manifest。

## 字体与素材

- 西文用 Geist，中文用 PingFang SC，中文、西文分别保存设置。数字随 Geist；不要换成圆体，也不要把全部文字套成系统等宽数字字体。
- 所有歌词使用设置中的同一字号，默认 22、Semibold；高亮靠透明度和位置表达，切句不改变字号或行高。
- 天气图标直接使用 `work/LumiBar/Assets/weather-icons-clean.png` 的 4×4 图集，透明底、无素材晕光。裁切索引见 JSON；不要用 emoji 或 SF Symbols 代替正常状态的天气素材。降水小图标也用同一图集。
- 功能图标保持细线。Mac 可用形态接近的 SF Symbols 轻字重或自绘等粗 Path；Windows 的 Segoe 私用区字符在 Mac 上没有对应字形，不能直接照抄编码。
- 字体路径和资源哈希见 manifest；沿用仓库既有的私有开发分发约定。

## 材质、圆角与层级

浮窗主表面圆角 12；外侧透明阴影边距 16。胶囊可见高度 34、圆角 17，窗口四周另留 10 的透明边距。阴影和上沿轻反光沿真实圆角轮廓，避免矩形裁切、黑角、亮竖线。

Windows 采用 Thin Acrylic。Mac 的材质用于承接背景模糊与明暗；字体、圆角和布局仍由本包控制。不要用一个默认 Liquid Glass 组件同时决定 29pt 圆角、整体放大、按钮形态和所有留白。按参考图调透明度、明度与局部光，主表面保持干净，浅色别铺一层灰黑。

默认玻璃密度 0.50、着色浓度 0.26、封面饱和度 0.80。密度变化只调中性覆盖层，别每帧重建整套材质或反复替换底图。JSON 同时记录 Windows 材质基线和 wash 计算方式，Mac 端按相同底板上的画面匹配。

天气光效位于图标附近的 UI 背景层，不能写入 PNG，也不铺满整个天气详情。雨、雪、雾、霾、沙尘、雷雨、晴夜都保留各自色组。音乐从封面取两个相近的亮色，过滤纯黑、灰和白；灰黑封面仍回退到有色亮色，避免灰脏大底或鲜红高饱和光斑。逐点公式继续参考 CoverPalette / AlbumLightColor，别只取平均色。

所有移动光层都要超出裁剪区足够多，经过圆角遮罩后才合成，移动时不能露出纹理矩形的边界。绘制采用预乘 Alpha、连续衰减和轻微静态抖色；不要移动一个刚好等于胶囊尺寸的硬边色块。

## 天气胶囊

源码：CapsuleGeometry.cs、CapsuleWindow.cs、CapsuleEdge.cs、WeatherAtmosphere.cs、RoundedLightSurface.cs。

| 项目 | 标准 | Lite |
|---|---:|---:|
| 可见高度 / 圆角 | 34 / 17 | 34 / 17 |
| 可见最小宽 | 104 | 64 |
| 主天气图标 | 24 | 22 |
| 温度字号 | 15，Semibold | 15，Semibold |
| 主图标和温度间距 | 4 | 3 |
| 降水图标 / 数字 | 14 / 11，数字 0.85 opacity | 不显示 |
| 降水图标和数字间距 | 2 | — |

标准状态是一行：主天气图标、温度、略小的降水图标和概率。两组垂直居中，左右留白按图对照。宽度按实际字体、温度和百分比测量，最低 104；`−20°`、`100%` 必须完整显示。不要给温度设置固定字符宽，也不要用缩小整行文字来修裁切。

Mac 菜单栏用自定义内容视图绘制完整胶囊，保留 NSStatusItem 的位置管理、点击与辅助功能。菜单栏高度容得下时采用原比例；高度更小时先压缩纵向留白、适度缩图标，保持文字可读和降水信息，横向尺寸继续测量。紧凑高度需在 Mac 实机校准，不能把 34pt 强塞入菜单栏，也不能把整块截图等比缩小成小字。

天气胶囊支持按天气变化的局部着色，跟随系统明暗。正常有数据时不用单独的裸温度标题、emoji 水滴或默认系统按钮背景替代胶囊。

## 天气悬停速览

源码：HoverPreviewWindow.cs。主表面 264×160，外加每边 16 的阴影。顶部一排：30 的天气图标、15/Semibold 的城市、11 的天气词、24/Semibold 的当前温度。使用 `°C`，不显示一长句说明。

下面三等栏居中：体感、降水、空气。标题 11，数字 22/Semibold，备注 10。体感数值只带 `°`；降水 `20%`，备注“未来 1 小时”；空气备注只写“良”“中度污染”等类别，不附重复的 CN AQI/US AQI。三栏的行框分别 18、31、17，行距 3，列距 10。

源码有 14.5/17.5 的左右内边距，用于图标透明边缘的光学平衡；Mac 端按截图和三栏中心位置核对，别只把数字相等当作视觉居中。速览不放逐时曲线、大温度展示区或完整降水图。

## 天气详情

源码：WeatherWindow.cs、TemperaturePalette.cs、WeatherAlertBadge.cs。主表面宽 480，高度跟内容及可用屏幕调整；内容左右内边距 22、上下 16，主要区块间距 8。

- 头部同一排：城市 24/Semibold → 天气源 11 → “上次更新：12:00”11；右侧小号刷新与更多。数据来源不再放底部，来源可点开说明。
- 城市行：定位城市胶囊 → 已收藏城市 → 紧挨最后一个城市的加号。定位城市与普通收藏的语义分开；定位图标不再在右侧重复出现。
- 当前天气三列：68 的图标、52 的温度、天气及说明，列距 12。当前大温度 `8°C`；说明按“最低 3° 最高 12° · 体感 5°”。
- 预警接在天气词后，两条短徽章相邻，只留很小的间距。图标颜色表达等级，文字只写“大风”“海上大风”等事件；点开才展示完整预警。更多预警汇总数量，保留全部详情。
- 未来一小时降水保留精简曲线区，按真实数据精度注明来源或缺测，不捏造分钟级预报。底部三指标的“降水”是概率，曲线的 mm 是降水量，字段不能混用。
- 24 小时预报用同一组横坐标排列曲线节点、温度、时间、天气图标。通常抽取 8 点；不让系统 Charts 自动刻度与下方手排图标各算一套位置。
- 10 天预报默认 4 行，展开其余行。固定列宽依次 112、32、58、剩余、36，列距 10，行最小高 28。日期是“今天 11/19”，日期与日名之间为半角空格，没有中点；天气图标各行垂直对齐。
- 温度色带：低温 `#4799FF` → 中间 `#A497DA` → 高温 `#FFA54F`。用整个预报的共同温域映射每天的温差段，不给每一天重置成完全相同的颜色。
- 底部一排五等栏：相对湿度、风速、空气、气压、紫外线。列距 12，标题 10、数字 16/Semibold，数字和标题都居中。单位放标题：`湿度 · 相对`、`风速 · km/h`、`空气 · CN AQI`、`气压 · hPa`、`紫外线 · UVI`；风向在数字旁用 10 的小号字。不要扩成 3×2 网格。

城市搜索、确认城市与十天展开共用一个高度动画时钟；先得到最终内容高度，再一起驱动内容裁剪和窗口尺寸。展开时不要同时重建整个天气树、滚动定位、跑另一条窗口弹簧，否则底部会抖。

## 音乐浮窗与歌词

源码：MusicWindow.cs、FadingLyricsHost.cs、Backend/LyricLayout.cs、Backend/LyricFade.cs、MarqueeTitle.cs。主表面 420×650，空间不足时按屏幕可用区域收缩；外加阴影边距。顶部只留播放器/歌词来源、减号、加号、更多；来源与歌词左缘对齐。关闭入口在更多菜单。

正文四周内边距 22/14/22/16。底栏封面 58×58、圆角 11；歌曲 19/Semibold、歌手 13/0.8、专辑 11/0.65。控制为细线上一首、播放/暂停、下一首，播放按钮 42；悬停底色取封面色，不染固定默认蓝。进度条取同一对封面色的渐变。

歌词字号默认 22，所有行同字号、Semibold；行间距 `clamp(size×0.5,9,18)`。活动行 1.0、不活动近邻 0.62、远处 0.30；切句不把其余行缩成 16，也不把长歌词截成一行。按实际换行高度排布。

排布公式见 JSON：step = size×1.3 + spacing；顶部延展 0.5 step，底部 1.5 step；高亮顶部锚点由 `clamp(step+48,80,128)+0.5step` 算出。不是整块居中，也不是只构造四行短文本。22 字号时 spacing=11、step=39.6、上延展19.8、下延展59.4、viewport=397.2、focusTop=107.4。

上下用歌词自身的 Alpha 遮罩渐隐，不能用玻璃色矩形盖住内容。渐隐中保留高亮整行和上下 8 的安全区域，长句换行后也要重新计算；原曲时间偏移只保存本曲。减号延后0.5秒，加号提前0.5秒，悬停标签说明。

层级从低到高：玻璃 → 双色封面柔光 → 歌词 → 频谱 → 来源与底栏控制。歌词与频谱/来源重合时，歌词位于下面；渐隐只影响歌词，不洗掉前景控件。

长歌名按真实字体宽度启用往返滚动：两端各停1.8秒，约22 DIP/秒，单程至少1秒。边缘遮罩 0/5%/95%/100%；控件区域宽度变化用260ms衔接。关闭动画时退为省略号；本包静态截图就是此模式。

## 设置与动效

设置主表面 560×650，顶栏54、侧栏及内容排布按截图。保留常规、外观、任务栏/入口、天气、音乐与歌词、插件、关于；Mac 的入口设置按平台改名，视觉分组与选择态保持。选中项悬停仍用强调色，别从蓝绿跳成灰白。九组强调色从源码导出在 JSON；音乐用封面色，不能拿设置强调色替代。

| 动效 | Windows 当前参数 |
|---|---|
| 悬停展示等待 | 320ms |
| 鼠标离开宽限 | 350ms，可跨进速览操作 |
| 悬停速览淡出 | 120ms |
| 详情/设置淡出 | 180ms，背景/内容/阴影一起 |
| 城市/十天展开、收起 | 280ms / 220ms，高度同一时钟 |
| 展开内容透明度 | 200ms / 140ms |
| 连续歌词跟随 | 680ms，smoothstep |
| 歌词行透明度过渡 | 520ms |
| 任务栏胶囊横向平移 | 220ms，ease-out cubic；Mac 音乐岛另适配 |
| 普通浮窗尺寸过渡 | 320ms，smoothstep |
| 封面两层柔光漂移 | 17s / 21s，低速合成 |

退出动效用完成回调；旧关闭回调不得隐藏刚重开的窗口。先让背景、内容与阴影一起淡完，再隐藏窗口、停/reset 光效。切歌只改数据、图片、颜色与歌词状态，不重建浮窗和材质。尊重减少动态效果；全屏、睡眠、多屏和菜单栏隐藏按 Mac 实机验收。

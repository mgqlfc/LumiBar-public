# Mac 实机验收

先加载 fixtures.json，固定主题、字体、玻璃密度、着色和频谱，使用同色底板。把 Retina 截图换算到 point 后裁到相同主表面，对齐内容边缘；外侧阴影单独比较。原始像素数和 Windows DPI 都记录在 manifest，不要凭截图文件尺寸推断 UI 字号。

## 静态对齐

- [ ] 标准天气胶囊一行显示图标、温度、小号降水；Lite只保留主图标与温度。
- [ ] −20°、100%、自定义宽字体都完整，内容居中，不用缩小整行补救。
- [ ] 胶囊圆角无黑角、毛边、矩形色带与侧边竖线；光移动到边缘时仍有自然覆盖。
- [ ] 天气速览上方一排，下方三等栏居中；AQI备注仅类别，左右空白视觉平衡。
- [ ] 天气标题同排城市、来源、上次更新时间；定位城市与收藏城市分开，加号紧跟末项。
- [ ] 当前温度带°C；最低/最高/体感的顺序、两条短预警位置一致。
- [ ] 24小时各列共用横坐标，十天日期与图标对齐，温度条共同温域蓝→紫→橙。
- [ ] 底部一排五栏居中、单位在标题、风向小号。
- [ ] 歌词所有行同字号，活动行不变大；中文和长英文换行完整，上下渐隐不盖高亮。
- [ ] 歌词位于频谱和来源之下；底栏有歌曲、歌手、专辑，来源与歌词左缘一致。
- [ ] 音乐控件细线，悬停取封面色；进度条同色渐变。
- [ ] 设置页侧栏、字号、九色强调色和选中悬停态与图一致。

## 交互与运动

- [ ] 天气胶囊悬停等待320ms；移出后有350ms宽限，120ms淡出。
- [ ] 悬停小窗可跨入并停留；不会叠加原生 tooltip。
- [ ] 点击详情后，点击当前活动窗口、桌面或弹窗外区域都能关闭；再点胶囊只切换一次。
- [ ] 详情180ms淡出，背景/内容/阴影同步，无黑闪、末帧亮框；快速关开不让旧回调关闭新窗口。
- [ ] 城市切换、确认、10天展开不抖；高度、裁剪、透明度共用同一动画生命周期。
- [ ] 歌词连续切句680ms跟随、520ms明暗过渡；跳播大跨度先定位，恢复正常逐句跟随。
- [ ] 加/减每次0.5秒，仅保存本曲；换歌、重开后正确读取。
- [ ] 长歌名启停阈值按真实字体宽度，双端渐隐、停顿和往返无跳动。
- [ ] 切歌不重建材质，双亮色连续交接；灰黑封面不使整窗灰脏。
- [ ] 减少动态效果时停漂移和跑马灯，文字仍完整可读或合理省略。

## Mac 入口与生命周期

- [ ] 菜单栏高度不足时只做必要压缩，天气主信息与降水可读；不截内容。
- [ ] 刘海左右不遮相机区域；无刘海/外屏采用独立居中音乐入口。
- [ ] 暂停保留入口、频谱停止；媒体会话结束才淡出。
- [ ] 菜单栏隐藏/恢复、切换桌面、多屏换主屏、睡眠唤醒、全屏都检查定位和层级。
- [ ] 关闭样例预览不会改系统音量、真实播放器进度、正式设置或自启动。

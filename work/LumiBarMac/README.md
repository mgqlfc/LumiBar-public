# LumiBar for Mac

LumiBar 的 macOS 27 客户端。音乐和天气在系统菜单栏用一组相邻的紧凑圆角胶囊。音乐显示小封面，右侧在播放时显示频谱，暂停时显示播放键。悬停时，胶囊下方的小卡显示曲目信息。天气显示彩色天气图标和温度。天气详情沿用原版彩色天气图标、局部柔光、逐时温度曲线和逐日温差条。天气与歌词浮窗采用 SwiftUI 的 Liquid Glass。原版图集和 Geist 从仓库内复用，中文默认跟随 macOS 系统字体。天气保留三列速览和完整预报，歌词页保留上下渐隐、封面柔光、底部频谱和播放进度。

[查看 macOS 更新记录](CHANGELOG.md)

## 构建

使用带 macOS 27 SDK 的 Xcode 或 Command Line Tools。从仓库根目录运行：

```sh
bash work/LumiBarMac/build.sh
open work/LumiBarMac/build/LumiBar.app
bash work/LumiBarMac/package.sh
```

构建脚本按当前 Mac 架构生成应用，并沿用仓库中的应用图标和天气图集。也可以给构建、打包脚本传入输出目录，以便保留正在使用的版本。默认使用临时签名，适合本机开发。可通过 `LUMIBAR_SIGN_IDENTITY` 指定签名身份。DMG 保存于 `work/LumiBarMac/build`，公开分发前需要 Developer ID 签名及 Apple 公证。

系统播控使用 BSD-3-Clause 的 [media-control](https://github.com/ungive/media-control)。构建会把可用的媒体桥接一同打包。可以从 Homebrew 安装 `media-control`，或用 `LUMIBAR_MEDIA_CONTROL_ROOT` 指向含有 `bin`、`lib` 和 `Frameworks` 的安装目录。

## 使用

- 音乐播放时，悬停后点击胶囊右侧的按钮可暂停。暂停后可直接点击同一位置恢复播放。移出音乐或天气胶囊会立即关闭各自的悬停小卡。音乐胶囊隐藏时，天气胶囊铺满并在右侧显示降水概率。点击天气胶囊打开详情，再点击收起。首次使用时搜索城市或点击定位图标。
- 天气优先使用原版的和风天气代理，失败时依次使用 Open-Meteo 和 MET Norway。定位按区县解析名称并继续用原坐标查询实况。预警取决于代理数据。
- 在带刘海的屏幕播放音乐时，Lumi 歌词显示在摄像头下方。点击歌词区域左上角的小图标展开。点击壁纸显示桌面或点击浮窗之外时，详情收回为紧凑歌词。展开后可查看歌词与播放进度，播放器支持跳转时可直接拖动进度。任一胶囊的右键菜单可立即隐藏或显示歌词。「显示设置」与右键菜单均提供暂停和全屏时自动隐藏的勾选项，暂停 5 秒后生效。
- 在「Lumi 歌词」的「颜色与光效」中，可分别调节收起和展开的流光速度。两项默认都是各自的 1× 速度，可调范围为 0.5× 到 3×。
- 在「天气胶囊」设置中可以添加、排序和移除收藏城市，也可以分别开关天气详情的实况、预警、预报及底部指标。风速可用 km/h、m/s 或按风速换算的蒲氏风级显示。
- 「显示设置」可独立隐藏天气和音乐胶囊。两个都隐藏时，从「应用程序」打开 LumiBar 可回到设置。「天气胶囊」和「音乐胶囊」各有等尺寸预览，可分别调节流光、着色、强度与饱和度。天气页还可选择 Lite 模式，音乐页可设置实时频谱和频谱响应。
- 展开歌词后，悬停左上角的加减按钮可查看本曲时移。连续点按时，标签会随时移量一起更新。
- 自带媒体桥接的构建优先订阅 macOS 正在播放会话，按系统时间戳和播放速率更新歌词。网易云和向系统报告播放状态的其他播放器可直接连接。跳转取决于播放器对系统命令的支持。缺少桥接时可继续使用原有播放器接入方式。
- 同步歌词同时查询网易云、AMLL、酷狗、QQ 音乐、汽水音乐、Deezer、咪咕、LRCLIB、酷我和 Megalobiz。AMLL 可直接查询官方 TTML 词库，同时保留网易云 ID 索引作为补充。通过录音版本校验的候选按元数据、实际逐字时间轴和译文评分。可在「播放与歌词来源」查看本曲匹配并锁定候选，亦支持 UTF-8 LRC 导入和逐曲偏移。
- 需要频谱时，在设置启用「实时频谱」，并授权系统音频录制。频谱只分析选中播放器的音频，不保留录音。

## 界面改动记录

以下是 Mac 版在实机反馈后调整的细节，可供 Windows 同步界面时参考。

- **歌词详情与曲目信息**。Lumi 歌词内当前歌词高亮，下一句淡化，换行时平滑移位。菜单栏的曲目信息卡内只显示封面、歌名、歌手和专辑。
- **歌词滚动条**。歌词区始终隐藏右侧滚动条，保留鼠标滚轮、触控板滚动和随播放进度同步滚动。连接鼠标、手动滚动和歌曲切换时都应保持右侧干净。
- **天气胶囊染色**。天气色铺满标准和 Lite 胶囊，叠加沿着胶囊缓慢流动的亮部。深色模式保留饱和度，浅色模式使用较柔和的染色。关闭动态光效或启用减弱动态效果时保留静态底色。
- **天气流光**。每团光晕绘制到完整的渐隐半径。晴夜和白天的流光在整个动画周期里都应平滑，经过绘制边界时不能出现直线色差。
- **天气浮窗外缘**。保留圆角玻璃和面板内的染色，移除天气详情和速览的额外外投影。用明暗分界明显的背景检查圆角外及窗口四边，确认桌面背景没有出现矩形半透明边。

## 视觉对照

预览使用 [Windows 还原包](../../outputs/Mac前端还原包/README.md) 的同一份样例与封面。每个窗口以逻辑尺寸绘制，浅色底板为 `#F3F5FA`，深色底板为 `#171922`。预览使用隔离的设置和样例播放数据。

打开菜单栏的交互样例：

```sh
open -n work/LumiBarMac/build/LumiBar.app --args --preview --weather --lyrics
open -n work/LumiBarMac/build/LumiBar.app --args --preview --weather-hover
```

逐窗对照时可指定 `weather`、`weather-hover`、`weather-capsule`、`weather-lite`、`weather-wide`、`weather-alerts`、`music` 或 `settings`。默认浅色，带 `--dark` 时显示深色。

```sh
open -n work/LumiBarMac/build/LumiBar.app --args --reference-case music --dark
```

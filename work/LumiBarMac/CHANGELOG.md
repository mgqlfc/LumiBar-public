# LumiBar for Mac 更新记录

本页汇总 GitHub 上一版 Mac 源码 0.1.16 之后的更新。

## 0.1.54（build 101）

- 修正收起歌词、展开详情和歌词管理中的西文词距。词间的连续空格、全角空格和制表符按一个普通空格排版，逐字高亮沿用原时间戳。

## 0.1.53（build 99）

- 前奏和可从逐字时间轴确认的间奏，按实际时长显示三点。收起时三点占一行，下排按正常分段规则预告下一句，开唱时直接接上同一段。
- 在歌词来源设置中，Apple Music 和其他支持逐字的来源一样标注「支持逐字」，连接状态单列一行。

## 0.1.17–0.1.52 累积更新

### 菜单栏和天气

- 天气和音乐以相邻胶囊显示。播放时分开，离开播放会话后合并。天气胶囊可固定为 Lite，温度和降水数字可以撑开胶囊。音乐胶囊支持封面取色、频谱和悬停播放键。
- 天气速览改为侧置实况，沿用天气光效。天气详情可管理收藏城市、按需显示各预报区块和指标，风速可用 km/h、m/s 或蒲氏风级显示。预警详情采用系统液态玻璃。

### Lumi 歌词和播放

- 收起时在摄像头下显示当前歌词和译文或续段。展开后可看完整歌词和播放详情，使用播控、音量、进度和按曲目记忆的歌词时移。播放器支持跳转时可直接拖动进度条。
- 增加长句分段、逐字高亮、前奏与间奏预告。Lumi 歌词的显示开关与菜单栏音乐胶囊独立，还可按暂停和全屏状态自动隐藏。
- 增加可选的系统液态玻璃，并提供收起和展开的尺寸、字体、描边、光效、HDR 等设置。中文默认使用 macOS 系统字体，西文默认使用 Geist。

### 歌词来源和歌词管理

- 增加并完善 AMLL、QQ 音乐、汽水音乐、Deezer 和可选连接的 Apple Music 等歌词源。自动匹配考虑歌名、歌手、专辑、时长和录音版本，通过版本校验后再考虑逐字时间轴与译文质量。
- 可为同一录音补入其他来源的译文，并分别显示原文和译文来源。歌曲记住手动选定的歌词，支持标记匹配错误、查看候选评分以及重新匹配。修正 Firefox 播放 Apple Music 时同一曲目因时长变化重复入库的问题。
- 增加独立歌词管理窗口，从设置、胶囊右键菜单和 Lumi 歌词菜单进入。支持搜索、排序、筛选、查看逐字时间轴、编辑歌词，以及导入和导出 LRC 或 TTML。批量重新匹配默认只处理缺少歌词的曲目。

### 设置

- 以系统液态玻璃重做设置和歌词管理控件。设置采用「通用」「菜单栏」「歌词」「关于」入口，并将天气和音乐的染色、流光和预览放到各自的胶囊设置。

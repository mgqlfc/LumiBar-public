# LumiBar 0.7.37 发布检查

日期：2026-11-15。目标：Windows 11 x64，当前用户安装。

## 本轮改动

- 高亮歌词回落半行距；视区上方增加半行距，下方增加 1.5 行距；上下渐隐随视区延长。
- 歌词低于频谱、来源提示和播放控制；实际播放时检查过换行歌词与上下渐隐。
- 天气来源移到城市标题旁、上次更新时间前，按钮只显示来源名称；来源详情仍可点击。
- 常规设置增加“导出诊断”，使用系统保存窗口选择 ZIP 路径。
- 诊断按白名单收集运行状态、有限日志与 24 小时内 LumiBar / Explorer 相关崩溃事件，过滤常见凭据、城市和媒体内容。
- 任务栏原生组件加载前校验 SHA-256，并复制到用户数据目录的内容寻址缓存；升级与卸载无需替换 Explorer 已加载的安装目录 DLL。
- 重复启动只激活现有窗口；安装器通过同用户命名管道请求正常退出。
- 着色浓度与饱和度保持原样。

## 复现构建

PowerShell 7 执行 `work/installer/build-release.ps1`。输出到全新的发布目录；Inno Setup 编译器路径为 `work/build-tools/InnoSetup7/ISCC.exe`。
发布目录确认不含个人数据后，再用 `work/installer/verify-package.ps1` 验证。验证脚本会在单独目录测试，并恢复原有登录启动项；已有正式安装时会拒绝使用同一个安装注册项做隔离测试。
